# 本地语音 · 热词词库【ASR 易错词专版 v1】
# 只收「听得清发音、但模型容易写错字」的词：低频专名、生僻/多音字、
#   以及名字本身正好是个常用词、会被同音常用字劫持的品牌与人名。
#
# 【怎么用】这是整包替换版，与通用版 hotwords.txt 二选一：
#   1) 下载后改名为 hotwords.txt，放进设备的 rime/voice/ 目录；
#   2) 或直接在「设置 → 本地语音 → 编辑热词词库」里把全文粘贴进去；
#   3) 改完点「重新载入词库文件」。
# 【格式】每行一个词，2-12 字；# 开头为注释，词后也可跟 # 备注；空行忽略。
# 【硬限制】文件最多存 200 条，但识别时只取前 60 条！
#   下面「默认生效」正好 60 条，已按对 ASR 的收益从高到低排好。
#   备选区 40 条全部注释掉了：想换词就去掉行首的 "# "，同时把用不到的默认行注释掉，
#   保证「前 60 条」都是你真的会说出口的词。切勿整段启用——100 条里后 40 条一个也不会生效。
#
# 【哪些词值得放 / 哪些别放】
#   值得放：低频专名、生僻字地名、多音姓氏、品牌产品名、你自己的联系人与项目代号。
#   别放：权利/权力、在/再、定金/订金 这类「两个写法都合法、要靠语义判断」的词——
#         热词只给指定词形加分，帮不了语义选择；
#         也别放「手机」「好看」这类高频通用词，模型本来就会写对，加了看不出变化。
#   ★ 收益最高的是第 5 组：把那些名人示例直接换成你自己的同事、客户、公司名。
#
# 【生效范围】Qwen3-ASR / FunASR Nano 走 config.hotwords（完整支持）；
#   流式 X-ASR / Parakeet 走 Transducer 词表通道（收益有限）；
#   SenseVoice / Paraformer / CTC 架构不支持热词，写了也不会传给识别器。
# 【测试建议】切到 Qwen3-ASR 0.6B，先只留「六安」一行，说「我下周去六安出差」，
#   开/关热词各一次对比；两次都一样说明词没进 native，而不是词库没选好。
# 全程本地处理，不联网、不上传音频与文字。本文件可直接编辑、可拷到其它设备复用。

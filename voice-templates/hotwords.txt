# 本地语音 · 热词 / 上下文词库（模板）
# 用法：把本文件放到设备的 rime/voice/ 目录，文件名保持 hotwords.txt；
#       再到「设置 → 本地语音 → 热词与上下文提示 → 重新载入词库文件」点一下即生效。
#       也可以直接在设置页「编辑热词 / 上下文词库」里粘贴本文件内容。
# 每行一个词；# 开头为注释，词后也可跟 # 备注；空行忽略。
# 词条长度 2-12 字，最多保存 200 条，识别时取前 60 条。
# 运行时还会动态合并 Rime 用户词库快照与光标前文字，这两路不写入本文件。
# 生效范围：Qwen3-ASR / FunASR Nano（config.hotwords）完整支持；
#           流式 X-ASR / Parakeet 走 Transducer 词表通道（收益有限）；
#           SenseVoice / Paraformer / CTC 架构不支持热词。
# 全程本地处理，不联网、不上传音频与文字。本文件可直接编辑、可拷到其它设备复用。
#
# 下面是示例，去掉行首 # 才会生效：
# 张三

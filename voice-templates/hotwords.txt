# 本地语音 · 热词词库（通用中文版 v2）
# 内容整理自网络公开词表：2025 年度字词/流行语、2026 上半年网络热词、
#   AI 大模型术语表、常用 App 清单、易读错地名表、中医穴位与方剂条目。出处见文末「词源」。
#
# 【怎么用】把本文件放到设备的 rime/voice/ 目录，文件名保持 hotwords.txt；
#   再到「设置 → 本地语音 → 热词与上下文提示 → 重新载入词库文件」点一下。
#   也可以直接在设置页「编辑热词 / 上下文词库」里粘贴本文件内容。
# 【格式】每行一个词，2-12 字；# 开头为注释，词后也可跟 # 备注；空行忽略。
# 【重要】文件最多存 200 条，但识别时只取前 60 条！
#   下面「默认生效」正好 60 条，按对 ASR 的收益从高到低排好了。
#   「备选分区」全部用 # 注释掉了：想换词，就把要用的行去掉行首的 "# "，
#   同时把用不到的默认行注释掉或删掉，保证生效的前 60 条都是你会说的词。
#   备选区有 149 条，请勿整段启用：会超过文件 200 条上限，而且多出来的词一个也不会生效。
# 【最管用的热词】其实是自己的人名、公司名、产品名、项目代号——见文末「我的自定义词」。
#
# 生效范围：Qwen3-ASR / FunASR Nano 走 config.hotwords（完整支持）；
#   流式 X-ASR / Parakeet 走 Transducer 词表通道（收益有限）；
#   SenseVoice / Paraformer / CTC 架构不支持热词，写了也不会传给识别器。
# 全程本地处理，不联网、不上传音频与文字。本文件可直接编辑、可拷到其它设备复用。

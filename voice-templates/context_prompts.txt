# 本地语音 · 场景 / 上下文提示词库（模板）
# 用法：把本文件放到设备的 rime/voice/ 目录，文件名保持 context_prompts.txt；
#       再到「设置 → 本地语音 → 场景提示词库 → 重新载入场景提示词库」点一下即生效。
#       也可以直接在设置页「编辑场景提示词库」里粘贴本文件内容。
# 每行一句自然语言，描述当前对话的领域、场景、人物或专有名词背景。
# 与 hotwords.txt 的区别：短词表让解码器更容易「选中这些词」，
#   这里让 LLM 架构「知道正在聊什么」，属于真正的上下文提示。
# 只对 Qwen3-ASR / FunASR Nano 这类 LLM 架构生效（写入 config.hotwords）；
#   SenseVoice / Paraformer / CTC / Transducer 架构不支持，写了也不会传给识别器。
# 最多 8 行、每行 120 字、合计 400 字；# 开头为注释，空行忽略。
# 内容参与识别器配置指纹：保存后会自动重新加载一次模型，但不会每次按键都重载。
# 全程本地处理，不联网、不上传音频与文字。本文件可直接编辑、可拷到其它设备复用。
#
# 下面是示例，去掉行首 # 才会生效：
# 这是一段中医诊疗对话，经常提到穴位、方剂和中药名。
